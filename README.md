# stock_market_data_analyzer
AI-powered stock market analysis system using Python, Machine Learning, and Data Visualization.

🔹 Key Features:
✔ Stock market data collection using Yahoo Finance API
✔ Moving Average & Trend Analysis
✔ Daily Return and Volatility Analysis
✔ AI-based Stock Movement Prediction
✔ Risk & Performance Analysis
✔ Interactive Data Visualization using Matplotlib

🛠 Technologies Used:
Python | Pandas | NumPy | Matplotlib | Scikit-learn | yFinance

• Financial Data Analysis
• Machine Learning Fundamentals
• Python Data Visualization
• Real-world Project Development
• Stock Market Trend Analysis
